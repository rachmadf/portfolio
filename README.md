## Architecture

The portfolio is developed using a modular Flask architecture based on Blueprints and service-layer components.

```text
portfolio/
├── app.py
├── routes/
├── services/
├── templates/
├── static/
├── MyFinance/
├── docs/
├── requirements.txt
└── README.md
```
