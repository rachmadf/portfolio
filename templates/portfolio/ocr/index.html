PROJECT OVERVIEW

About OCR Text Extractor.

A lightweight web application that converts text in screenshots and image files into editable, downloadable text using PaddleOCR.

01 · PURPOSE

Problem statement

Manually transcribing text from screenshots and images can be slow and error-prone. This project provides a simple browser-based workflow for extracting printed text so users can reuse it in documents, notes, and other applications.

02 · OBJECTIVES

Project objectives

  • Accept common image formats.
  • Extract text with PaddleOCR.
  • Present the result in an editable text area.
  • Save and download text as a UTF-8 TXT file.

03 · USERS

Intended users

Students, educators, office workers, researchers, and anyone who needs to copy printed text from screenshots or image files.

04 · CORE FEATURES

Functional requirements

  • Upload PNG, JPG/JPEG, BMP, TIFF, or WEBP images up to 10 MB.
  • Preview the selected image before extraction.
  • Display extracted text and allow editing.
  • Copy text to the clipboard.
  • Save extracted output in the server's output/ folder and download it.

05 · WORKFLOW

How it works

  1. Select or drop an image into the upload area.
  2. Submit the image for OCR processing.
  3. Review and edit the recognized text.
  4. Copy the text or download the TXT result.

06 · TECHNOLOGY

Technology stack

PythonFlaskPaddleOCRPaddlePaddleHTMLCSSJavaScript

The OCR service currently uses PaddleOCR configured for English text (lang="en") with angle classification enabled. Recognition quality depends on image clarity, orientation, and text layout.

07 · NON-FUNCTIONAL REQUIREMENTS

Usability, validation, and privacy

  • Responsive interface for desktop and mobile screens.
  • Validate file type and enforce an upload size limit.
  • Use unique filenames for generated results.
  • Remove temporary uploaded images after processing.
  • Handle missing files and OCR errors with clear messages.
  • Keep generated TXT files on the server until cleaned up by the operator.
